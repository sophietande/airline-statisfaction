# airline-satisfaction

Calcul et prédiction de la satisfaction des clients de compagnies aériennes à l'aide d'algorithmes d'apprentissage automatique (Machine Learning).

## Équipe et répartition des tâches
Ce projet a été réalisé par :
* **Myriam YAVO** : Analyse des données, calcul des moyennes et implémentation des scripts de prédiction.
* **Stève Christian FANTE** : Analyse des données et implémentation des scripts de prédiction, analyse des prédictions.
* **Sophie TANDE** : Analyse des données, calcul des moyennes et implémentation des scripts de prédiction.

---

## Fonctionnalités
Ce projet permet de charger des données clients, de les préparer et d'entraîner des modèles de classification pour prédire si un passager est satisfait ou non de son vol. Il compare notamment deux approches :
* **Decision Tree** (Arbre de décision)
* **Random Forest** (Forêt aléatoire)

## Prérequis
Le projet a été développé et testé avec la configuration suivante :
* **Python 3.14.7**
* Bibliothèques requises : `pandas`, `numpy`, `scikit-learn`

## Installation

1. **Clonez le dépôt ou téléchargez les fichiers :**
   ```bash
   git clone https://github.com/sophietande/airline-statisfaction.git
   ```

2. **Installez les dépendances nécessaires :**
   ```bash
   pip install pandas numpy scikit-learn
   ```

## Utilisation

Assurez-vous d'avoir placé votre fichier de données dans le dossier du projet, puis lancez le script principal unique :

```bash
python main.py
```
